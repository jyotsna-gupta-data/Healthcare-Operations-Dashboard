# 🏥 Healthcare Operations & Patient Analytics Dashboard

An interactive Tableau dashboard that turns raw hospital data into clean, easy-to-read insights for hospital managers.

---

## 📈 Key Highlights & Insights

* **Hospital Efficiency:** Patients stay for an average of **4.1 days**, with strong recovery scores averaging **74.72**.
* **Busiest Department:** **Orthopedics** had the highest number of patients (1,068 patients).
* **Main Age Group:** Adults aged **31–45** make up the largest patient group (1,716 patients).
* **Revenue:** Tracked **$274.6M** in total hospital revenue.
* **Steady Demand:** Patient numbers and gender balance remain steady across all regions and care types.

---

## 🛠️ Tools & Features Used
* **Tableau:** Built interactive screens, clean KPI cards, and used a simple grey-and-blue design with no extra gridlines.
* **Smart Charts:** Created custom **Treemaps** (for age groups) and **Donut Charts** (for visit types and care paths).
* **Data Preparation:** Cleaned and organized raw healthcare data into clear business metrics.
